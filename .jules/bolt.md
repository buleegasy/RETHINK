## 2024-07-20 - Prevent UI Churn During Text Streaming with Targeted Zustand Selectors
**Learning:** Subscribing to frequently updating arrays like `messages` in Zustand causes severe unnecessary re-renders in components that only care about specific, rarely-changing properties within those arrays (like a `techChain` on the last message). During text streaming, `messages` updates constantly, crippling performance if heavy UI components (like `AmbientGlow`) are subscribed to it.
**Action:** Always use highly targeted, memoized selectors in Zustand stores when dealing with streaming state. Instead of `const messages = useChatStore(state => state.messages);`, extract only the data needed: `const lastTechChain = useChatStore(state => state.messages.findLast(m => m.role === 'assistant')?.techChain);`. Or better yet, manage the specific derived state explicitly if it's complex.
